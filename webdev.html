Learning Path

শেখার রোডম্যাপ

এই ধাপগুলো ক্রম অনুযায়ী ফলো করলে তুমি নিজেই একটা পূর্ণাঙ্গ ওয়েবসাইট বানাতে পারবে।

STEP 01

🌐 ইন্টারনেট ও ওয়েব বেসিক

ওয়েবসাইট কীভাবে কাজ করে, ব্রাউজার কী করে, সার্ভার-ক্লায়েন্ট সম্পর্ক — বেসিক ধারণা।

STEP 02

🧱 HTML — কাঠামো

ট্যাগ, এলিমেন্ট, অ্যাট্রিবিউট, ফর্ম, ইমেজ, লিংক আর সেমান্টিক HTML শিখো।

STEP 03

🎨 CSS — ডিজাইন

কালার, ফন্ট, বক্স মডেল, Flexbox, Grid, রেসপন্সিভ ডিজাইন ও অ্যানিমেশন।

STEP 04

⚡ JavaScript — প্রাণ

ভেরিয়েবল, ফাংশন, লুপ, DOM ম্যানিপুলেশন, ইভেন্ট আর অ্যাসিনক্রোনাস কোড।

STEP 05

🛠️ প্রজেক্ট বানাও

টু-ডু লিস্ট, ক্যালকুলেটর, ওয়েদার অ্যাপ — হাতে-কলমে প্র্যাকটিস করো।

STEP 06

🚀 Git, হোস্টিং ও পরবর্তী

GitHub-এ কোড রাখো, Netlify-তে ডিপ্লয় করো, তারপর React/Node শেখো।

HTML

ওয়েবসাইটের কাঠামো বা হাড়গোড়। কনটেন্ট কী আর কোথায় থাকবে তা HTML ঠিক করে।

  • ট্যাগ ও এলিমেন্ট
  • হেডিং, প্যারাগ্রাফ, লিস্ট
  • লিংক, ইমেজ, ভিডিও
  • ফর্ম ও ইনপুট
  • সেমান্টিক HTML5
{ }

CSS

সাজসজ্জা ও লেআউট। রঙ, সাইজ, পজিশন আর অ্যানিমেশন সব CSS-এর কাজ।

  • সিলেক্টর ও স্পেসিফিসিটি
  • বক্স মডেল
  • Flexbox ও CSS Grid
  • রেসপন্সিভ মিডিয়া কোয়েরি
  • Transition ও Keyframe অ্যানিমেশন
JS

JavaScript

ওয়েবসাইটের প্রাণ। ক্লিক, স্ক্রল, ডাটা — সব ইন্টারঅ্যাকশন JS দিয়ে হয়।

  • ভেরিয়েবল ও ডাটা টাইপ
  • ফাংশন ও অ্যারে
  • DOM ম্যানিপুলেশন
  • ইভেন্ট হ্যান্ডলিং
  • Fetch API ও Async/Await
